# Project Vision

## North Star

PECS is an AI-native engineering cognition operating system. It compounds engineering intelligence over time by storing persistent memory, surfacing contextual knowledge, and integrating AI deeply into developer workflows.

## Target User

Senior engineers and engineering leads who:
- Work across multiple repositories and contexts
- Lose institutional knowledge when switching tasks or teams
- Want AI assistance grounded in their actual codebase, not generic advice
- Value local-first, privacy-preserving tools

## Success Metrics (Phase 1)

- Engineer records first memory within 5 minutes of install
- Repo summary generated correctly for 3 different repo types (TypeScript, Python, Go)
- Search returns relevant results with < 200ms latency
- Extension adds < 100ms to VSCode startup time
- Zero data leaves the machine without explicit user action

## Non-Goals

- Generic productivity dashboard
- Cloud-dependent operation (cloud sync is optional, never required)
- Replacing existing tools (GitHub Copilot, linear, Notion) — PECS augments them
- Multi-user collaboration in Phase 1
- Mobile or web UI in Phase 1
